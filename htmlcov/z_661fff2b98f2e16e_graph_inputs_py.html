88 This does not change the graph; use :func:`project_objects2urban_graph` to insert objects into it. 

89 

90 Args: 

91 urban_graph: Graph whose ``edges_gdf`` contains line geometries. 

92 gdf: GeoDataFrame with geometries to match to graph edges. 

93 max_dist: Optional search radius in graph CRS units; objects farther from every edge get missing 

94 values. ``None`` searches without a limit.

98 ``v`` (and ``k`` for multigraphs), ``dist`` (distance from the object to the edge) and ``along`` 

99 (distance from the start of the edge geometry to the closest point on it). When several edges are 

100 equally near, one of them is returned.

102 Raises: 

103 TypeError: If ``gdf`` is not a GeoDataFrame. 

104 ValueError: If the graph has no edges or geometries cannot be matched safely.

117 points_geom.values, return_all=False, max_distance=max_dist, return_distance=True

124 series = pd.Series(values, index=gdf.index[object_pos]).reindex(gdf.index) 

125 if pd.api.types.is_integer_dtype(np.asarray(values).dtype):
