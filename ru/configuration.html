Настройки¶

IduEdu хранит настройки времени выполнения в одном глобальном объекте iduedu.config. Функции загрузки и построения графов читают его при каждом вызове, поэтому изменение действует на всё, что выполняется после него в том же процессе. Большинство настроек можно также задать переменными окружения, которые читаются один раз при импорте iduedu.

from iduedu import config

config.to_dict()  # a snapshot of every current setting

Сервер Overpass и запросы¶

from iduedu import config

config.set_overpass_url("https://overpass-api.de/api/interpreter")
config.set_timeout(120)
config.set_rate_limit(min_interval=2.0, max_retries=5, backoff_base=2.0)

  • set_overpass_url принимает любой интерпретатор Overpass по http:// или https://, например собственный сервер или зеркало.

  • set_timeout задаёт тайм-аут запроса в секундах. То же значение передаётся Overpass как [timeout:...] в каждом запросе.

  • set_rate_limit разносит запросы не менее чем на min_interval секунд. Перед каждой попыткой IduEdu спрашивает у сервера свободный слот через /status и ждёт его. При сетевых ошибках и ответах HTTP 429, 502, 503 и 504 запрос повторяется до max_retries раз с экспоненциально растущей задержкой на основе backoff_base; при ответе 429 учитывается заголовок сервера Retry-After.

  • config.user_agent отправляется с каждым запросом. Укажите в нём то, что идентифицирует ваш проект: config.user_agent = "my-project/1.0 (me@example.org)".

  • config.proxies (словарь в стиле requests, например {"https": "http://proxy:3128"}) и config.verify_ssl передаются в каждый запрос.

Публичным сервером Overpass пользуется множество людей. Оставляйте темп запросов по умолчанию, если у вас нет собственного сервера.

Кеш Overpass¶

IduEdu кеширует исходные JSON-ответы Overpass на диске: границы, запросы уличных сетей, отношения-маршруты и их участников. Кеш включён по умолчанию и находится в .iduedu_cache относительно текущей рабочей папки.

from iduedu import config

config.set_overpass_cache(enabled=False)  # ignore the cache completely
config.set_overpass_cache(cache_dir="/tmp/overpass_cache", enabled=True)

Кеш хранит только ответы, а не обработанные графы. Очистите папку или отключите кеш, чтобы заново загрузить данные, например после правки нужных вам данных OSM.

Исторические снимки¶

Overpass может ответить на запрос по состоянию OpenStreetMap на заданный момент:

from iduedu import config

config.set_overpass_date(date="2020-01-01")                # 2020-01-01T00:00:00Z
config.set_overpass_date(date="2020-01-01T12:34:56Z")
config.set_overpass_date(year=2020, month=5)               # 2020-05-01T00:00:00Z
config.set_overpass_date()                                 # back to current data

Пока дата задана, маршруты метро запрашиваются как обычные отношения-маршруты: зоны остановок, станции и входы пропускаются, потому что Overpass ненадёжно выполняет такие запросы на произвольный момент времени, и в журнал пишется предупреждение.

Локальные файлы OSM¶

from iduedu import config

config.set_osm_source("pbf", path="city.osm.pbf")  # every builder reads the file
config.set_osm_source("overpass")                  # back to the default

В режиме pbf кэш Overpass не используется, а overpass_date игнорируется. Источники данных описывает use_pbf, скачивание из Geofabrik, файлы городов и отличия от Overpass.

Индикаторы прогресса и журналирование¶

from iduedu import config

config.set_enable_tqdm(False)  # hide progress bars while public-transport routes are parsed
config.configure_logging(level="INFO")
config.configure_logging(level="DEBUG", to_file="iduedu.log")

IduEdu пишет журнал через loguru, доступный как config.logger. В чистом интерпретаторе IduEdu при импорте заменяет стандартный приёмник loguru, чтобы её собственные сообщения выводились начиная с LOG_LEVEL (по умолчанию WARNING), а сообщения других пакетов сохраняли стандартные уровень и формат. Приложение, которое настроило loguru до импорта IduEdu, сохраняет свои приёмники нетронутыми и получает в них сообщения IduEdu; отключить их можно через logger.disable("iduedu"). configure_logging заменяет только приёмники, добавленные им раньше, и стандартный приёмник loguru, затем пишет сообщения IduEdu уровня level и выше в стандартный поток ошибок и, с to_file, в файл с ротацией по 20 МБ и хранением 14 дней. json=True пишет только текст сообщения без времени и уровня — для сборщиков, которые добавляют их сами.

Индикаторы выполнения показываются, когда стандартный поток ошибок — терминал или код выполняется в Jupyter, и скрыты в сервисах и задачах по расписанию; ENABLE_TQDM или set_enable_tqdm переопределяют это.

class iduedu.config.Config[исходный код]¶

Глобальные настройки времени выполнения: источник данных OSM, Overpass, кеширование, журналирование и построение графов.

configure_logging(level='INFO', *, to_file=None, json=False)[исходный код]¶

Пишет сообщения IduEdu уровня level и выше в стандартный поток ошибок и, с to_file, в файл.

Заменяются только приёмники, добавленные предыдущим вызовом, и стандартный приёмник loguru; приёмники, добавленные приложением, остаются. Когда стандартный приёмник заменяется, сообщения других пакетов сохраняют его уровень и формат.

Параметры:

  • level (Literal['TRACE', 'DEBUG', 'INFO', 'WARNING', 'ERROR', 'CRITICAL'])

  • to_file (str | None)

  • json (bool)

Параметры:

set_overpass_date(date=None, *, year=None, month=None, day=None)[исходный код]¶

Задаёт дату снимка для запросов к Overpass.

Дата хранится в формате ISO 8601 UTC: YYYY-MM-DDTHH:MM:SSZ и подставляется в заголовок запроса Overpass как [date:"..."]. Этот метод позволяет зафиксировать данные OSM на определённом историческом снимке или вернуться к «текущим» данным.

Примеры использования:

  • set_overpass_date() или set_overpass_date(None) — сбросить дату (без [date:...] в запросах).

  • set_overpass_date(date="2020-01-01") -> 2020-01-01T00:00:00Z.

  • set_overpass_date(date="2020-01-01T12:34:56Z") -> сохраняет нормализованное значение этой метки времени.

  • set_overpass_date(year=2020) -> 2020-01-01T00:00:00Z.

  • set_overpass_date(year=2020, month=5) -> 2020-05-01T00:00:00Z.

  • set_overpass_date(year=2020, month=5, day=10) -> 2020-05-10T00:00:00Z.

Параметры:

  • date (str | None) – Строка даты в формате YYYY-MM-DD или YYYY-MM-DDTHH:MM:SSZ. Если она передана, year, month и day должны быть None.

  • year (int | None) – Год. Если дата задаётся без date, нужно указать хотя бы год; month и day необязательны и по умолчанию дают 1 января.

  • month (int | None) – Месяц (1–12). Необязателен вместе с year. По умолчанию 1 (январь).

  • day (int | None) – День (1–31). Необязателен вместе с year и month. По умолчанию 1.

Исключение:

ValueError – Если переданы и date, и любой из year, month, day, если строка даты в неподдерживаемом формате или если получившаяся дата недопустима.

set_osm_source(source, *, path=None)[исходный код]¶

Выбирает источник данных OpenStreetMap.

"overpass" (по умолчанию) отправляет запросы в Overpass API. "pbf" отвечает на те же запросы по локальному файлу .osm.pbf, который читает ядро IduEdu на Rust; кеш Overpass и overpass_date тогда не используются.

Параметры:

  • source (Literal['overpass', 'pbf']) – "overpass" или "pbf".

  • path (str | PathLike | None) – Файл OSM для "pbf". Можно не указывать, если pbf_path уже задан. Для "overpass" только сохраняется.

Исключение:

  • ValueError – Для неизвестного источника или "pbf" без файла.

  • FileNotFoundError – Если файл не существует.

use_pbf(path=None, *, osm_id=None, territory=None, region=None, **download_kwargs)[исходный код]¶

Временно читает данные OSM из локального файла; при выходе восстанавливается прежний источник.

Файл либо задаётся путём path, либо скачивается для территории: osm_id, territory, region и любые другие именованные аргументы без изменений передаются в download_osm_pbf(), которая выбирает выгрузку Geofabrik, кеширует её и вырезает территорию. Уже закешированный файл используется повторно без загрузки. Также доступна как iduedu.use_pbf.

Параметры:

  • path (str | PathLike | None) – Файл .osm.pbf.

  • osm_id (int | None) – Идентификатор отношения OSM территории для загрузки, вместо path.

  • territory (Polygon | MultiPolygon | GeoDataFrame | GeoSeries | None) – Полигон территории в EPSG:4326 либо GeoDataFrame/GeoSeries, вместо path.

  • region (str | None) – Идентификатор региона Geofabrik, из которого вырезается территория; если не указан, выбирается автоматически.

  • **download_kwargs – Прочие аргументы download_osm_pbf() (update, out_dir, name, …).

Исключение:

ValueError – Если переданы и path, и аргументы загрузки, или ни то, ни другое.

Тип результата:

Iterator[Config]

Пример

>>> with config.use_pbf("berlin.osm.pbf"):
...     walk = get_walk_graph(territory=polygon)
>>> with iduedu.use_pbf(osm_id=1114252, region="northwestern-fed-district"):
...     graph = get_intermodal_graph(osm_id=1114252)
