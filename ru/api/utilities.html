Утилиты для графов¶

Связность¶

Функции связности изучают компоненты графа и полезны перед маршрутизацией или расчётом OD-матриц. Для неориентированных графов используйте connected_components(); для ориентированных выбирайте между weakly_connected_components() и strongly_connected_components().

Функции largest_* возвращают множества идентификаторов узлов. Чтобы действительно оставить только наибольшую компоненту, используйте UrbanGraph.keep_largest_connected_component() или параметр keep_largest_subgraph функций построения.

Работающий пример анализа связности — в Диагностика связности.

Редактирование и преобразование¶

Функции редактирования возвращают новые объекты UrbanGraph и не меняют исходный граф, если только вы не используете соответствующий метод UrbanGraph с inplace=True.

Используйте subgraph_by_nodes() для подграфов, порождённых узлами, clip_urban_graph() для обрезки по геометрии, relabel_urban_graph() для плотной нумерации узлов и join_urban_graphs() для объединения таблиц совместимых графов.

Используйте UrbanGraph.to_directed(), UrbanGraph.to_undirected() и UrbanGraph.simplify_multiedges() для преобразований топологии.

Примеры редактирования — в Операции с графами.

Сопоставление и проецирование объектов¶

Используйте nearest_nodes(), когда таблице объектов нужен лишь идентификатор ближайшего существующего узла графа.

Используйте project_objects2urban_graph(), когда объекты нужно встроить в топологию графа. Функция готовит объект UrbanGraphChanges с новыми узлами, новыми рёбрами и исходными рёбрами для удаления. Примените изменения с помощью apply_urban_graph_changes() или воспользуйтесь сокращением в памяти UrbanGraph.project_objects().

Оба сценария, включая add_link_edge=True и add_link_edge=False, — в Объекты, ближайшие узлы и проецирование на граф.

Сохранение¶

Используйте write_urban_graph() и read_urban_graph(), чтобы сохранять и восстанавливать архивы .urbangraph. Архивы содержат таблицы узлов и рёбер и могут включать закешированную матрицу смежности. См. Основы UrbanGraph.

connected_components

Возвращает компоненты связности неориентированного UrbanGraph.

weakly_connected_components

Возвращает компоненты слабой связности.

strongly_connected_components

Возвращает компоненты сильной связности.

number_connected_components

Возвращает число компонент связности неориентированного графа.

number_weakly_connected_components

Возвращает число компонент слабой связности.

number_strongly_connected_components

Возвращает число компонент сильной связности.

largest_connected_component

Возвращает наибольшую компоненту связности неориентированного графа.

largest_weakly_connected_component

Возвращает наибольшую компоненту слабой связности.

largest_strongly_connected_component

Возвращает наибольшую компоненту сильной связности.

largest_component

Возвращает наибольшую компоненту в выбранном режиме связности.

keep_largest_connected_component

Оставляет только наибольшую компоненту UrbanGraph.

relabel_urban_graph

Перенумеровывает идентификаторы узлов в плотный RangeIndex и обновляет концы рёбер.

subgraph_by_nodes

Возвращает подграф UrbanGraph, порождённый переданными идентификаторами узлов.

clip_urban_graph

Обрезает узлы графа по геометрии и оставляет только рёбра с сохранившимися концами.

join_urban_graphs

Объединяет два совместимых UrbanGraph, соединяя таблицы узлов и рёбер.

simplify_multiedges

Сводит мультиграф UrbanGraph к простому графу.

to_directed

Возвращает ориентированную копию UrbanGraph по логическому столбцу направления рёбер.

to_undirected

Возвращает неориентированную копию UrbanGraph.

nearest_nodes

Возвращает идентификатор ближайшего узла графа для каждой входной геометрии.

project_objects2urban_graph

Готовит изменения графа, присоединяющие объекты к ближайшим рёбрам.

apply_urban_graph_changes

Применяет подготовленные изменения к UrbanGraph.

UrbanGraphChanges

Набор изменений таблиц, который можно применить к UrbanGraph.

read_urban_graph

Читает UrbanGraph из архива .urbangraph.

write_urban_graph

Записывает UrbanGraph в архив .urbangraph.

validate_graph

Проверяет все требования к узлам, рёбрам, топологии и системе координат UrbanGraph.

Необязательные утилиты NetworkX¶

NetworkX не устанавливается вместе с IduEdu. Установите его отдельно (pip install networkx), чтобы пользоваться функциями ниже; без него они при вызове вызывают ImportError.

urban_graph2nx_graph

Преобразует UrbanGraph в граф NetworkX.

nx_graph2urban_graph

Преобразует граф NetworkX в UrbanGraph.

graph2gdf

Преобразует граф NetworkX в GeoDataFrame узлов и/или рёбер.

gdf2graph

Преобразует GeoDataFrame линий LineString в ориентированный граф (nx.DiGraph).

keep_largest_nx_component

Оставляет только наибольшую компоненту связности графа NetworkX.

clip_nx_graph

Обрезает граф NetworkX по полигону и возвращает порождённый подграф.

read_gml

Читает файл GML в граф NetworkX и преобразует geometry рёбер из строк WKT в объекты shapely.

write_gml

Записывает граф NetworkX в GML, приводя координаты узлов к обычным числам с плавающей точкой.

reproject_graph

Перепроецирует координаты узлов (x, y) и геометрии рёбер в новую систему координат (на месте).
