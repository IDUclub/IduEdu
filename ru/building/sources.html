Обзор¶

Построители графов OSM читают OpenStreetMap из одного из двух источников, а построитель GTFS читает локальное расписание.

Источник

Для чего

Как выбрать

Overpass API (по умолчанию)

Одна территория за раз, текущие данные или прошлая дата, без файлов

config.set_overpass_url, config.set_overpass_date (см. Настройки)

Локальный файл .osm.pbf

Много территорий, воспроизводимые расчёты, работа без Overpass

config.set_osm_source("pbf", path=...) или with use_pbf(...)

Фид GTFS Schedule

Общественный транспорт со временем движения и ожидания по расписанию

get_gtfs_public_transport_graph() (см. Общественный транспорт из GTFS)

Каждый построитель отвечает на одни и те же вопросы из любого источника OSM: линии улиц типа сети, отношения маршрутов общественного транспорта, зоны остановок метро и граница территории. Фильтры и выбор по полигону одинаковы, поэтому граф, построенный по файлу, совпадает с графом, построенным через Overpass на момент, который отражает файл.

Территория¶

Каждый построитель принимает территорию как osm_id (отношение OSM, например муниципальную границу) или как territory: полигон shapely в EPSG:4326 (долгота, широта) или GeoDataFrame в любой системе координат. get_4326_boundary() возвращает полигон, который используют построители. Граф строится в локальной проекционной системе координат, оценённой по территории, поэтому длины в метрах. Линии и маршруты, касающиеся полигона, читаются целиком; clip_by_territory=True обрезает рёбра по границе.

boundary = iduedu.get_4326_boundary(osm_id=1114252)        # Vasilyevsky Island, Saint Petersburg
walk = iduedu.get_walk_graph(territory=boundary, clip_by_territory=True)

Overpass API¶

По умолчанию построители отправляют запросы к публичному экземпляру Overpass. Ответы кэшируются на диске в .iduedu_cache, запросы разносятся по времени и повторяются, а config.set_overpass_date отвечает на запрос так, как OpenStreetMap выглядел в прошлый момент. Настройки описывает адрес сервера, кэш, темп запросов и даты снимков.

Локальные файлы OSM¶

Rust-ядро IduEdu читает файлы .osm.pbf без других зависимостей. Читается только .osm.pbf; файлы .osm или .opl сначала преобразуйте, например командой osmium cat city.osm -o city.osm.pbf.

from iduedu import config, get_public_transport_graph, get_walk_graph, use_pbf

config.set_osm_source("pbf", path="city.osm.pbf")   # every following call reads the file
walk = get_walk_graph(territory=city_polygon)
config.set_osm_source("overpass")                   # back to the default

with use_pbf("city.osm.pbf"):                       # or only inside a block
    pt = get_public_transport_graph(territory=city_polygon, transport_types=["bus", "tram", "subway"])

Переменные окружения IDUEDU_OSM_SOURCE=pbf и IDUEDU_PBF_PATH=/data/city.osm.pbf делают то же при импорте. В режиме pbf кэш Overpass не используется, а overpass_date игнорируется: файл сам является снимком, и snapshot_time() возвращает момент, который он отражает, из его заголовка (osmosis_replication_timestamp, задаётся в выгрузках Geofabrik).

Загрузка из Geofabrik¶

download_osm_pbf() принимает территорию в том же виде, что и построители, и возвращает небольшой файл этой территории. Она выбирает наименьшую выгрузку Geofabrik, покрывающую территорию, скачивает её один раз (прерванное скачивание продолжается, а сумма md5, публикуемая Geofabrik, проверяется) и вырезает территорию функцией split_by_polygons(). use_pbf() принимает те же аргументы, скачивает файл и читает из него внутри блока.

with iduedu.use_pbf(osm_id=1114252, region="northwestern-fed-district"):
    boundary = iduedu.get_4326_boundary(osm_id=1114252)
    graph = iduedu.get_intermodal_graph(territory=boundary, clip_by_territory=True)

with iduedu.use_pbf(territory=city_polygon):        # the extract is chosen from the territory
    walk = iduedu.get_walk_graph(territory=city_polygon)

С region граница osm_id читается из выгрузки, и запрос к Overpass не делается; без него граница один раз запрашивается через Overpass, чтобы выбрать выгрузку. territory не нужно ни то ни другое. Выгрузки и вырезанные файлы кэшируются в config.overpass_cache_dir (geofabrik/ и geofabrik/territories/). Существующий вырезанный файл возвращается без скачивания, а кэшированная выгрузка используется, пока update=True не запросит более новый файл Geofabrik. geofabrik_regions() перечисляет выгрузки с их контурами, а find_geofabrik_region() называет наименьшую, покрывающую территорию.

Файлы городов из региональной выгрузки¶

Запрос к файлу размером со страну просматривает его целиком для каждой территории. split_by_polygons() за один проход режет его на небольшие файлы городов, сразу для всех городов региона:

from iduedu import snapshot_time, split_by_polygons

paths = split_by_polygons(
    "russia-northwestern-fed-district-latest.osm.pbf",
    {"spb": spb_polygon, "petrozavodsk": ptz_polygon},
    "cities/",
)
snapshot_time(paths["spb"])                  # the replication timestamp of the extract is kept

Каждый файл города сохраняет полностью и с тегами:

  • линии улиц (highway, railway, public_transport), касающиеся полигона;

  • отношения маршрутов общественного транспорта, касающиеся его, со всеми их членами, в том числе вне полигона;

  • для метро — каждое отношение, имеющее общий узел с линией (её зоны остановок), их членов и группы зон остановок, которые их содержат;

  • отношения, перечисленные в keep_relations, например границу, чтобы osm_id продолжал работать.

Метаданные элементов (версии, отметки времени, пользователи) не копируются. Графы, построенные по файлу города, совпадают с построенными по региональному файлу для того же полигона или любого полигона внутри него.

Отличия от Overpass¶

  • Элементы возвращаются в порядке id. Overpass возвращает ответы по маршрутам в порядке квадратов (quadtile), поэтому id узлов и рёбер графа общественного транспорта могут быть пронумерованы иначе, хотя граф тот же.

  • Точки на границе полигона считаются внутренними. Overpass в редких случаях может иначе обрабатывать точные попадания на границу и длинные стороны полигона.

  • Поддерживаются только фильтры по тегам (["k"], [!"k"], ["k"="v"], ["k"!="v"], ["k"~"re"], ["k"!~"re"], с необязательным флагом ,i для регулярных выражений); другой синтаксис Overpass в custom_filter вызывает UnsupportedFilterError. Регулярные выражения используют модуль Python re.

  • Данные, которых нет в файле, найти нельзя: члены отношения, отсутствующие в файле, не имеют геометрии. Используйте split_by_polygons() или полную региональную выгрузку и избегайте узкой обрезки.

  • split_by_polygons() отбирает линии по положению, только если у них есть один из way_keys; custom_filter по другим ключам требует way_keys=None (или списка, который их включает) при нарезке файлов городов.

Функции¶

get_4326_boundary

Приводит границу территории к одному полигону Polygon в EPSG:4326.

use_pbf

Временно читает данные OSM из локального файла или из территории, скачанной из Geofabrik.

download_osm_pbf

Файл OSM для территории, вырезанный из выгрузки Geofabrik: прямая замена загрузки из Overpass.

download_geofabrik_region

Скачивает выгрузку Geofabrik region (идентификатор из geofabrik_regions()).

find_geofabrik_region

Идентификатор наименьшей выгрузки Geofabrik, полностью покрывающей territory (EPSG:4326 для объектов shapely).

geofabrik_regions

Выгрузки Geofabrik в виде GeoDataFrame в EPSG:4326.

PbfSource

Локальный файл OpenStreetMap .osm.pbf, отвечающий на запросы, которые IduEdu иначе отправляет в Overpass.

split_by_polygons

Записывает по одному компактному, полному по ссылкам <name>.osm.pbf на каждый полигон из региональной выгрузки.

snapshot_time

Возвращает момент, на который составлен файл OSM, из его заголовка, как datetime в UTC с часовым поясом.

Фильтры тегов Overpass в читателе файлов:

parse_way_filter

Разбирает фильтр тегов Overpass, например ["highway"]["access"!~"private"].

WayFilter

Разобранный фильтр тегов Overpass; вызов со словарём тегов говорит, подходят ли теги.

UnsupportedFilterError

Возникает для синтаксиса фильтров Overpass, который читатель .pbf не может вычислить.

Ограничения¶

  • Файл отражает один момент; для другой даты скачайте более новую выгрузку или используйте config.set_overpass_date с Overpass.

  • Выгрузка Geofabrik для большого региона — это большой файл (около 650 МБ для Северо-Западного федерального округа России); он скачивается один раз и кэшируется.

  • Графы из Overpass и из файла другой даты различаются на правки, сделанные между ними.
